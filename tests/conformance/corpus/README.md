# Local conformance corpus

Drop any `.adoc` file in this directory and it joins the conformance suite
(`tests/conformance/conformance.test.ts`) — the real documents that motivate
this project are the best adversarial inputs. Committing a dropped file is
optional but note this is a public repo; keep private documents local-only (they
still run for you, but quarantine entries for them would not make sense to
commit).
